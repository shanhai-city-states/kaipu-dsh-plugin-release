# apps/shell · 零门槛分发形态（⏳ 后置 · Step 1 只有本说明）

> ★ **本目录不是"客户端"，是"零门槛分发形态"。**
> 它**不改变**"插件为主"这件事 —— 见根 `README.md` §〇/§一。

---

## 1. 它为什么存在

只有一种情况需要它：

> **客户没有 DSH，而且不懂技术。**

| 客户情况 | 谁出宿主 | 我们交什么 | 需要本目录吗 |
|:--|:--|:--|:-:|
| 已有 DSH（Web / 自建） | 客户 | **只交插件包** | ❌ |
| 没有 DSH，但会折腾 | 客户自己起 | 插件包 + 安装引导 | ❌ |
| 没有 DSH，且不懂技术 | **我们** | 安装包 | ★ **需要** |

## 2. ★★ 一条硬纪律：壳里不得有任何 083 业务代码

壳只做三件事：

1. **起窗口**（隐藏创建 → 加载完成 + 300ms 才 `show()`）
2. **起 DSH 侧车**（`profile 随包携带`，显式 `DSH_HOME`，`CREATE_NO_WINDOW`）
3. **把 DSH 地址给 WebView**

**业务全在 `packages/plugin-*` 里。** 这条一旦破：
插件就不能独立分发 ⇒ 生态入口（R1「进门不要钱」/ R2「一天能接进来」/ R7「装了就能跑」）全废。

★ 依据：`004-客户端插件化 §九 #5`「壳是否要感知插件？→ **不感知**（壳只管窗口与侧车；插件全在 ②③ 层）」。

## 3. 从 003 搬什么（Step 5 才做）

| 搬 | 内容 | 003 出处 |
|:--|:--|:--|
| ✅ | Tauri 壳骨架：窗口、侧车编排、`CREATE_NO_WINDOW`、显式 `DSH_HOME`、profile 随包 | `003` 的 `002-桌面端-Tauri/` |
| ❌ | **一切财税业务代码与种子数据** | — |
| ⚠️ | 打包/体积脚本（**改口径，不照抄**：083 目标 安装包 ≤200MB / 装机 ≤500MB） | 003 的体积清单工具 |

## 4. 003 的两条硬约束（搬的时候必须带上）

| # | 约束 | 为什么 |
|:-:|:--|:--|
| **W1** | **WebView2 必须 `--no-sandbox`** | 否则被安全软件注入搞崩；**手动传 `additional_browser_args` 会让 Tauri 默认参数串静默丢失**，要补上 |
| **W2** | 壳 spawn node / `taskkill` **必须 `CREATE_NO_WINDOW`** | 否则弹黑框；**关掉黑框 = 杀掉侧车** |
