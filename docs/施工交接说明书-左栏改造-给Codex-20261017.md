### 任务 3 · 推荐明确对应场景（**做不了，见下**）

**现状**：推荐项渲染的是

```tsx
r.label   // "快速看一眼" / "完整会商"
r.when    // "适合：就一个东西，想快点知道有没有硬伤"
```

**问题**：用户看到"快速看一眼"，**不知道它对应左栏里哪一场场景** —— 要自己猜。

**⚠️ 但这不能只改前端**：
`recommendations` 来自 `snap.recommendations`（服务端契约），当前字段只有 `{ label, when }`，
**没有场景标识**。要"明确对应场景"必须**契约加字段**（如 `sceneKey`）⇒ 属服务端协作项。

**⇒ 本轮施工请这样处理（二选一，先做②）**：

1. **（不要做）** 前端硬猜 label→场景的映射。硬编码映射会在服务端换数据时**静默错位**。
2. **（本轮做）** 在推荐块 hint 里把关系说清，降低猜的成本：
   现有 hint 是「按场合推荐。选之前看一眼，就不用逐个点开猜。」
   → 建议改为明确指向：「按场合推荐。**照着名字去下面的「场景」里找同名的**。」
   —— 这样即使没有字段关联，用户也知道"推荐名 = 场景名"这条规则。
3. **（留给阿舟）** 提契约变更：`Recommendation` 加 `sceneKey`，前端改为可点击直接选中。

**★ 施工时请明确回复：你选了哪条、以及你对"推荐名是否真的等于场景名"有没有核实过。**
若没核实，就**不要写"找同名的"**（那会变成一句没根据的话）。
