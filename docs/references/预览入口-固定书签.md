# 预览入口 · 固定书签（一次换票，30 天免 token）

> **出处**：阿舟（施工方）｜**日期**：2026-10-06
> **解决什么**：`dsh web authentication required; reopen the URL printed by dsh web.` 反复出现。

---

## 一、根因（一句话）

**你书签里存的是"一次性入场券"，不是"工牌"。**

| 东西 | 从哪来 | 活多久 | 该不该存进书签 |
|:--|:--|:--|:--:|
| `?token=<32位>` | DSH 每次启动新生成，**不落盘** | **只在当前进程活着** | ❌ 存了必 401 |
| `dsh-auth-…=v1.<…>` cookie | 用上面那个 token 换来的 | **Max-Age=2592000 = 30 天** | ✅ 存这个 |

实测（2026-10-06）：

```bash
curl -i "http://127.0.0.1:3090/?token=0SUhz…"
# HTTP/1.1 303 See Other
# location: ./
# set-cookie: dsh-auth-4b6qQ-…=v1.<payload>; Max-Age=2592000; Path=/; HttpOnly; SameSite=Strict
```

- 直接访问 `http://127.0.0.1:3090/`（**不带任何票**）⇒ `401 dsh web authentication required`
- 带上 `?token=` ⇒ `303` + **下发一张 30 天 cookie**
- 带上那张 cookie 再访问 `/` ⇒ `200` ✓

⇒ **token 换 cookie 是一次性的，换完就能把那串 token 扔掉。**

---

## 二、怎么固定（三条路，按省事排序）

### 路 A · 粘 cookie（推荐，30 天不动）

1. 起 DSH，然后跑：

   ```bash
   node dev/open-dsh.mjs --print-cookie
   ```

   它会打出这样一行：

   ```
   dsh-auth-4b6qQ-Y94Wo8ht4uQsOr6Rc6e47Y7zHxdRsr_25sj5o=v1.eyJ…; Max-Age=2592000; Path=/; HttpOnly; SameSite=Strict
   ```

2. 浏览器打开 `http://127.0.0.1:3090/`
3. `F12` → **Application（应用）** → 左侧 **Cookies** → `http://127.0.0.1:3090`
4. 新建一条：
   - **Name**：`dsh-auth-4b6qQ-Y94Wo8ht4uQsOr6Rc6e47Y7zHxdRsr_25sj5o`（等号左边整段）
   - **Value**：`v1.eyJ…`（等号右边整段，**到分号为止**）
   - Domain `127.0.0.1` / Path `/`
5. 刷新 ⇒ 进得去。**此后书签就存 `http://127.0.0.1:3090/`（干净地址，不带 `?token=`）。**

> ⚠️ 粘完第一次可能要多刷一次（个别浏览器对新写入的 cookie 要重新读一次），属正常。

### 路 B · 每次重启跑一行（最省事，但每次要跑）

```bash
node dev/open-dsh.mjs            # 自动取当前有效 token 并打开浏览器
node dev/open-dsh.mjs --check    # 只探活（脚本/快捷方式用，能换票 exit 0，作废 exit 1）
```

### 路 C · 桌面快捷方式（双击即开）

在桌面建个 `.cmd`：

```bat
@echo off
cd /d "<插件仓根目录>"
node dev\open-dsh.mjs
```

双击即可 —— 它自己会从**最新日志里挑出仍然有效的那个 token**（不用你猜哪个日志是当前进程的）。

---

## 三、什么时候 cookie 也会失效

| 情况 | 表现 | 出路 |
|:--|:--|:--|
| 满了 30 天 | 401 | 重走路 A |
| **DSH 换了端口** | 连不上 / 401 | cookie 是按 `127.0.0.1:3090` 这个 **authority** 签的（payload 里写着 `"authority":"127.0.0.1:3090"`）⇒ **端口一换，旧 cookie 立即作废**，重走路 A |
| DSH 重启（**端口不变**） | ✅ cookie 仍有效 | 不用管 |

> 实测 payload：`{"version":1,"authority":"127.0.0.1:3090","issuedAt":…,"expiresAt":…}`
> ⇒ **判据：cookie 绑的是 `host:port`，不是绑进程。** 所以只要端口不动，重启不掉线。

---

## 四、一句话记忆

> **`?token=` 是入场券（一次性），cookie 是工牌（30 天）。**
> **书签存地址、cookie 存票 —— 别把票抄进书签。**
