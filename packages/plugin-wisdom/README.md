# @shanhai/kaipu-wisdom-team · 会商组织插件

> **可单独装 / 可不装。** 卸掉它，场地仍完整可用 —— 这是本包存在的**前提**，不是附加条件。

## 它是什么

一个**内置的会商组织**：当使用者没有自带 Agent 时，装上它即可开箱使用场地。

> **它是可替换的默认值，不是场地的必需件。** 使用者可以接入自己的 Agent 替代它 ——
> 「任何一个位置都能被替换」，场地才算真正开放。

## 两种使用姿态

| 姿态 | 何时 | 特征 |
|:--|:--|:--|
| **默认内置** | 使用者没带自己的 Agent | 开箱即用 |
| **可被替换** | 使用者带了自己的 Agent | **任一位置都能被使用者自己的 Agent 顶替** |

## 「可摘除」约束

| 检查项 | 怎么验证 | 当前 |
|:--|:--|:-:|
| `@shanhai/kaipu-platform` **不依赖**本包 | 查 platform 的 `package.json` dependencies | ✅ |
| 本包**不往场地插件的座位里塞东西** | 两个 client half 的 `slots.register` 各自独立 | ✅ |
| 摘掉本包目录 + patch 段 ⇒ 场地仍完整 | 配套解耦检查脚本 | ✅ |
| 零 Agent 时界面显「**待接入**」 | `SceneLamp.agentId === null` 的渲染 | 后续版本 |

## 本包**不含**什么

- ❌ 任何 Agent 的 skill / memory / 内部提示词（那些只在服务端）
- ❌ 规则库全文
- ❌ 任何密钥

> 本包是**会商流程的客户端呈现面**，不是任何 Agent 的实现。

## 当前状态

**骨架版**：结构上可摘除（静态证据齐）。可运行的会商视图在后续版本。
